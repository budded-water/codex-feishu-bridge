# Single-action screenshot review

A capable project's screenshot card should let the private owner accept and
merge the shown candidate in one click. The owner can quote the card for
changes or conflict resolution. A provider-confirmed merge produces one
question about deployment or release in the same conversation.

Reuse the visual receipt, provider workflow, state ledger and task-reply
routing. The project adapter qualifies the exact candidate and provides the
provider receipt. Enrollment requires a merge path that leaves release to a
separate decision. Capture, hosted checks, independent review and production
release continue to use each project's rules.
