# Owner native permissions

## Why

The enrolled remote owner currently approves routine native escalations manually. Make native permission policy explicit for this Bot, reuse Codex auto-review and support deliberately remembered command rules, while retaining genuine owner intervention and uncertain-outcome protections.

## Scope

Opt-in owner-private P1 execution policy; exact native approval proposals and persistent user-layer rules; rule inspection/revocation; native auto-review observations; and one explicitly authorized retry of a recorded denied command. No new scheduler, model-backed policy manager, unrestricted sandbox, credential migration or automatic write replay. Existing deployments inherit native settings until explicitly configured.

Source implementation, current-head review/CI, native protocol/model evidence, managed rollout and real owner acceptance are separate gates. P3 business validation and deferred host exercises remain open.
