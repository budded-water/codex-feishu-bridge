## Why

The owner should be able to change topics and send the first task in one
message. Existing reply anchors, registered PRs and the current matter are
useful defaults for continuation.

## Scope

Recognize explicit new-topic phrases and direct requests about a single
unbound GitHub PR. Reuse its existing binding when available. Retain ambiguous
new work for a one-click choice. Show the actual destination in the existing
receipt. Keep gateway admission, task authority and current-matter selection
separate from routing a single quoted reply.
